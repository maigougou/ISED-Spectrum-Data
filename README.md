# ISED Spectrum Data

Public database releases for North Cell Towers. This repository contains only downloadable data, update manifests and data provenance documentation. Database generation runs in a private environment.

- [Current update manifest — schema 2 / prepared 12](channels/v2.json)
- [Legacy schema 1 manifest](channels/v1.json)
- [Latest database release](https://github.com/maigougou/ISED-Spectrum-Data/releases/latest)
- [Publication status](status.json)
- [Data provenance](ATTRIBUTION.md)
- [Retained source fields](FIELD_SELECTION.md)

Verify downloads against the SHA-256 checksum in the manifest. Reported sites and antenna directions do not represent measured coverage or live service availability.

The current database requires North Towers 1.0.0 (Build 27) or later. Earlier builds use the legacy channel. When upgrading to Build 27, install the new offline database when prompted; personal favourites and notes are retained.
